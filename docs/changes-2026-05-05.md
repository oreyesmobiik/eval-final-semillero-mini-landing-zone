# Cambios Aplicados - 2026-05-05

Documento de trazabilidad tecnica de ajustes realizados durante iteraciones de despliegue.

## 1. Correcciones de Bootstrap

Archivo: `scripts/bootstrap.ps1`

- Se robustecio la invocacion de Azure CLI para entornos Windows donde `az` no esta en PATH, usando `python.exe -m azure.cli` cuando aplica.
- Se corrigio la deteccion de existencia de Storage Account (consulta por lista y conteo) para evitar falsos positivos por mensajes de error.
- Se agrego asignacion RBAC minima para backend remoto (`Storage Blob Data Contributor`) al Service Principal.

Impacto:
- Bootstrap idempotente y mas estable en entornos con PATH inconsistente.

## 2. Estabilizacion de Terraform (evitar churn recurrente)

Archivo: `infra/modules/aks/main.tf`

- Se declaro `upgrade_settings` explicitamente en:
  - `default_node_pool`
  - `azurerm_kubernetes_cluster_node_pool.user`

Impacto:
- Se elimina drift recurrente por diferencias de defaults reportadas por API de AKS.

## 3. Actualizacion por deprecaciones AzureRM

Archivo: `infra/main.tf`

- En `azurerm_federated_identity_credential` se migro:
  - de `parent_id`
  - a `user_assigned_identity_id`
- Se removio `resource_group_name` de recursos donde el provider lo marca deprecado/no usado.

Impacto:
- Menos warnings y mejor compatibilidad hacia AzureRM v5.

## 4. Gobernanza (Policies)

Archivo: `infra/modules/policy/main.tf`

- Se agrego tercera policy custom y su assignment:
  - `deny-public-access-storage-mini-lz`

Impacto:
- Se cumple el minimo de tres policies asignadas en alcance de Resource Group.

## 5. Observabilidad

Archivo: `infra/modules/monitoring/main.tf`

- Se mantuvo alerta KQL con query resiliente ante variaciones de schema (`column_ifexists`).
- Se agregaron diagnosticos hacia Log Analytics para:
  - AKS
  - Key Vault
  - NSG de subnet AKS
  - NSG de subnet Private Endpoints

Impacto:
- Alertas de logs mas robustas para Container Insights y cobertura ampliada de telemetria de seguridad/plataforma.

## 6. Operacion de costo: Cleanup

Archivo nuevo: `scripts/cleanup.ps1`

- Script para destruir infraestructura Terraform con `SupportsShouldProcess`.
- Opcion `-DeleteTfState` para borrar backend remoto (container/storage/RG de tfstate).

Impacto:
- Operacion de apagado completo para control de costos.

## 7. Resultado de estado

- Plan Terraform actual: sin cambios funcionales pendientes (estado convergente).
- Despliegue completo validado con outputs finales en Terraform.
